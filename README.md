# Real-Time Object Detection Radar System

## Project Overview

This project is a real-time object detection radar prototype developed using Arduino UNO, an ultrasonic sensor, an SG90 servo motor, and Wi-Fi connectivity.

The system is designed to detect nearby objects, measure distances, and display their positions through a radar-style visualization interface.

## Hardware Components

- Arduino UNO
- Ultrasonic Sensor
- SG90 Servo Motor
- Wi-Fi Connectivity Module / Interface
- Jumper Wires
- Power Supply
- Mounting Structure

## Working Principle

1. The SG90 servo motor rotates the ultrasonic sensor across the scanning area.
2. The ultrasonic sensor emits sound pulses and receives reflected echoes.
3. Arduino UNO calculates the distance of detected objects.
4. The system associates distance measurements with the sensor's scanning angle.
5. Detection data is transmitted to the radar visualization interface using the implemented communication setup.
6. The radar display represents detected objects in real time.
